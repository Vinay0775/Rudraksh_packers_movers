# Rudraksh_packers_movers

India's premier Packers & Movers web application featuring a dynamic moving cost calculator, live estimation wizard, rate charts, and admin control dashboard.

## Features
- **Interactive Moving Cost Calculator**: Multi-step wizard for shifting estimates.
- **Rate Charts & Charges**: Rate tables for local shifting & domestic relocation.
- **Customized Blue Footer**: Direct WhatsApp booking integration and social links.
- **Admin Dashboard**: Dynamic theme switcher, rate manager, and booking manager.

## Structure
- Frontend/: Customer landing page (index.html), stylesheet (style.css), customer app script (pp.js), and admin control panel (dmin.html, dmin.js).
- Backend/: Server-side services.
